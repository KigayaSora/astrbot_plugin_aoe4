# astrbot_plugin_aoe4 —— 帝国时代4战绩查询

基于 [AoE4World](https://aoe4world.com) API 的 AstrBot 插件，以图片卡片形式查询《帝国时代4》玩家数据。

## 指令

| 指令 | 说明 |
|---|---|
| `/aoe4 战绩 <玩家名>` | 各模式天梯段位、分数、胜率、排名（别名：段位、rank） |
| `/aoe4 隐藏分 <玩家名>` | 各模式 ELO/MMR 汇总：当前/历史最高/近7天/近30天（别名：elo、mmr、分） |
| `/aoe4 对局 <玩家名> [数量]` | 最近对局：胜负、文明、地图、时长、分数变化（默认 8 场，上限 20） |
| `/aoe4 单局 <玩家名> [序号]` | 单场对局详情：双方队伍玩家、文明、分数变化（1=最近一场）（别名：局、详情、game） |
| `/aoe4 胜率 [模式] [段位]` | 文明胜率排行（模式：排位1v1~4v4、匹配1v1~4v4；段位：青铜/白银/黄金/铂金/钻石/征服者，仅整段过滤）（别名：文明、civ） |
| `/aoe4 帮助` | 用法说明 |

指令组别名：`/帝国` 等同 `/aoe4`。玩家名至少 3 个字符，可含空格；优先精确匹配同名玩家。

## 安装

1. 将本目录放入 AstrBot 的 `data/plugins/` 下（或在 WebUI 插件页通过 zip 上传安装）。
2. 依赖：`aiohttp`、`jinja2`（AstrBot 内核已内置 aiohttp；见 requirements.txt）。
3. 图片卡片依赖 AstrBot 的文转图（t2i）能力，请确保 AstrBot 的 t2i/Playwright 环境可用；不可用时可在 WebUI 配置。
4. 在 WebUI 重载插件后使用。

## 配置项（WebUI 可视化）

- `timeout`：请求超时（秒），默认 10
- `cache_ttl`：接口缓存时长（秒），默认 120
- `default_matches`：对局默认场数，默认 8
- `civ_rows`：文明卡展示条数，默认 15
- `user_agent`：请求 UA
- `max_retry`：429/5xx 重试次数，默认 2

## 说明

- 数据来自 aoe4world.com 公开接口（v0），ELO 为网站基于对局数据推算，非游戏官方内部 MMR。
- 接口未公开限流策略，插件内置 ≤1 req/s 限速、429 退避重试与响应缓存，请节制使用。
